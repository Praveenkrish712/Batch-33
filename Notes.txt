===> To Create a Webpage
===> It is not a Programming Language
===> It is a Markup Language
===> Every website can start with HTML

1) Heading - h1 to h6

2) Paragraph - p

3) hr

4) Break Tag - br

5) Text Formatting - i, b or strong, u, sup, sub and Mark

6) Anchor Tag - a

7) Image Tag - img

8) List - ordered list and unordered list

9) Tables - th, tr and td

10) Forms - Label, input, placeholder, required, button, type(important), fieldset and legend

11) Media Elements - Audio and Video

12) Semantic Tags - Header, footer, Section and nav

13) Divion(div) tag and Span
    div ----> Block level Elements (Ex: Heading,p and div)
    Span ----> Inline Elements (Ex: span, a, img and media Elements)
